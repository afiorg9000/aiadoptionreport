## Typography

### Fonts
| Role | Font | Where to get it |
|---|---|---|
| Headings / display | **Playfair Display** | Google Fonts — free |
| Body / UI / labels | **Inter** | Google Fonts — free |

Both are available in Canva's font library by searching the name directly.

| Element | Font | Weight | Approx size |
|---|---|---|---|
| Report title (H1) | Playfair Display | Bold (700) | 48–56 px |
| Section title (H2) | Playfair Display | SemiBold (600) | 32–36 px |
| Subsection (H3) | Playfair Display | Medium (500) | 22–24 px |

## Voice / tone notes (for infographic copy)

- Lead with the **adoption–value gap**: broad use, narrow measurable return
- Use the **government figures** (~17–20%) as the headline, not the 88% consulting-survey number
- Tier labels: **Leaders / Advanced / Emerging / Nascent** (not numbered tiers alone)
- Cite evidence tiers where relevant: **Tier A** = government/peer-reviewed, **Tier B** = major analyst surveys, **Tier C** = directional only
- Honest framing: "most firms report using AI; most cannot yet show a return for it"
